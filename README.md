## 🚀 Recursos Principais

- **Design Responsivo & Elegante**: Construído em HTML5 + Tailwind CSS com a paleta de cores inspirada no Partido Missão (Preto, Branco e Dourado `#FFC700`).
- **Comutador de Idiomas (PT-BR 🇧🇷 / EN 🇺🇸)**: Suporte completo i18n com detecção automática do idioma padrão do navegador (`navigator.language`) e persistência no `localStorage`.
- **Efeito Interativo `card-lift`**: Animação de seleção estilo baralho em cards de competências, projetos e contatos.
- **Integração em Tempo Real com a API do GitHub**: Consumo dinâmico dos repositórios via `https://api.github.com/users/mateus-andriola/repos` com busca instantânea e filtros por linguagem (Go, TypeScript, Elixir, Rust, Mobile).
- **Métricas de Engenharia Empíricas**: 161.999 linhas de código autorais analisadas via parseamento AST com `Graphify`.
- **Favicons Nativos**: Ícones vetoriais em `.svg` e formato multi-resolução `.ico`.

## 🌐 Como Executar Localmente ou Publicar

### Visualização Local:
Basta abrir o arquivo `index.html` em qualquer navegador web moderno.

### Implantação Gratuita (GitHub Pages, Vercel ou Netlify):
1. **GitHub Pages**: Vá em *Settings* > *Pages* no repositório GitHub e selecione a branch `main` como root.
2. **Vercel / Netlify**: Conecte este repositório `curriculo_profile` e faça o deploy automático sem necessidade de build step.
